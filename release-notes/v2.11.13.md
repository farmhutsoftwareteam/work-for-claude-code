# Atelier 2.11.13 — voice input: permission + stability fixes

- **Fixed the microphone permission for voice input.** Atelier now asks for **microphone** access first, so it reliably shows up in System Settings → Privacy → Microphone. And because Microphone and Speech Recognition are two separate toggles, if the one that's off is Speech Recognition, the banner and the "open System Settings" button now send you to the *right* pane instead of the wrong one.
- **Fixed a crash when starting dictation.** If the mic wasn't ready the instant you started talking, dictation could take the whole app down. It now fails gracefully (and tells you) instead of crashing.
