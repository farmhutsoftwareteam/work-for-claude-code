# Atelier 2.11.11 — a real shell window, and another MCP sign-in fix

- **The co-driven terminal is now a proper floating window.** When the agent (or you, with ⌘⇧T) opens a shell you both share, it no longer stacks a full terminal pane directly above your composer — it floats in its own draggable panel, with a tab for each concurrent shell and a status badge (running / needs you / done / failed). The conversation stays a conversation; a compact receipt row marks when it happened and lets you jump back in.
- The window only pulls itself to the front and grabs your keyboard when a shell genuinely needs you to type something (like a password prompt) — everything else stays out of your way until you open it.
- Fixed another case of MCP sign-in (Supabase and other OAuth providers) failing with a malformed authorization link.
