# Atelier 2.11.14 — MCP recovery, and a fix for lost chats

- **Fixed the app and a dev build clobbering each other's open chats.** Your workspace — which chats you have open — is now saved per build, so running a development build alongside the shipped app no longer overwrites each other's tabs. (If a chat still comes back empty, it's because the underlying session file was pruned; keeping our own copy of the transcript is coming next.)
- **A failed MCP server is no longer a dead end.** When a server (Supabase, Kapso, and the like) shows “failed,” you can now **Reconnect** it right from the panel, and a **“why?”** button shows the actual reason it failed. If it really just needs sign-in, that option appears after it retries.
- **A server that drops mid-conversation now says so** — a one-line note in the transcript, instead of silently going dark until you happen to open the MCP panel.
- A server stuck “starting” too long is now treated as a reconnectable failure rather than an endless spinner.
