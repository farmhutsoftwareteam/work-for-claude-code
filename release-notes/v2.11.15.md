# Atelier 2.11.15 — adding an MCP server, rebuilt

Adding an MCP server used to make you know things you shouldn't have to. This is a ground-up pass on that whole flow, informed by how the best MCP tools do it.

- **Add a server with one field.** Paste a URL *or* a command (`npx -y @scope/server`) and Atelier figures out the rest — it detects the transport for you instead of asking you to pick stdio / HTTP / SSE, and auto-suggests a name. The manual controls are still there, folded into "Advanced".
- **Test before you save.** A **test** button (and an automatic check on save) actually connects — reaching a remote server's handshake, or confirming a local command exists on your PATH — and tells you ✓ / needs-sign-in / what went wrong, so a bad config is caught up front instead of failing silently later.
- **One-click popular servers.** A new **Popular** section in the marketplace installs well-known servers (Filesystem, Git, Fetch, Memory, Playwright, GitHub, and more) straight into a prefilled editor — no hunting GitHub, no hand-writing a command.
- **Clearer scope.** Project scope now spells out that it's shared with your team, commits to `.mcp.json`, and asks each teammate to approve it — and steers you to `${ENV_VAR}` references instead of pasting a secret into a committed file.
