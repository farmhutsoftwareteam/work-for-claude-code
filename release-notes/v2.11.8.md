# Atelier 2.11.8 — dictation, done properly

- **Dictate as long as you want.** The mic no longer cuts out on a pause or at the one-minute mark — talk through pauses, think out loud, rant an idea; it keeps listening until you stop it.
- **You can see it listening.** A live waveform, a pulse, and an elapsed timer while you speak — instead of a button that just greyed out and looked dead.
- **Clearer transcription.** Recognition now runs on Apple's more accurate engine by default, with automatic punctuation so what you say comes out as readable text; it falls back to on-device automatically when you're offline.
- **Fewer rough edges.** The mic turns off when you send, keeps working when you switch audio devices mid-sentence, and — if microphone or speech access is off — the button now takes you straight to the right System Settings pane instead of doing nothing.
