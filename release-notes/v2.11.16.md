# Atelier 2.11.16 — MCP self-heal

When an MCP server won't connect, Atelier now helps you fix it instead of leaving you at a dead end.

- **Approve a project server in one click.** A server from a repo's `.mcp.json` that's waiting on Claude's one-time approval now shows an **approve** button — it grants the approval and reconnects — instead of a "sign in to retry" prompt that could never fix it (approval isn't sign-in). This is the fix for the *"expo … review it first"* trap.
- **"Ask agent" to fix a stuck server.** On a failing or needs-sign-in server, hand it to the agent: it diagnoses in the shared co-driven terminal and, if the server needs sign-in, runs the login so you finish in your **browser** — the agent never sees or handles your credentials. (You can also just ask it in chat.)
