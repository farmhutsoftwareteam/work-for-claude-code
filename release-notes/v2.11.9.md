# Atelier 2.11.9 — agent runs you can actually follow

When a session fans work out to many sub-agents at once, it used to print one card per agent — 20 agents meant 20 cards stacked on the composer, un-scannable and pushing the conversation off-screen. That's fixed.

- **A whole fan-out is now one row.** Delegating to N agents shows a single batch row — overall state, a live count (done · running · failed), and a cell per agent that fills in as each finishes. Click it to expand into the individual agents.
- **A live Agents panel.** The dock's Agents panel now has three tabs: **running** (every delegated agent live — what it is, how long it's taken, what it's doing, with a "stop all"), **session** (every fan-out this session), and **definitions** (your agent types, as before).
- **You always know they're working.** The agents tab shows a running count (red if one failed), and a "N agents running" chip appears in the composer — click it, or press ⌥A, to jump straight to the panel.

Works for both Claude and Codex sessions.
