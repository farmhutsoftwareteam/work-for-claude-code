# Atelier 2.11.24 — Skills you can see, and clearer states

- **Installed packs always show their skills.** The Skills list now reflects what's actually installed (read from Claude's own plugin state, not just settings), including packs that are installed but turned off — shown with an **enable** action instead of vanishing.
- **"disabled" → "on-demand".** A skill that only runs when you type its command is now labeled **on-demand** (with a tooltip), not the misleading "disabled".
- **Sign back in after any signout.** If a session ends because your Claude login expired — not only mid-turn — the **Sign in** prompt now appears.
- **Dev-build note.** A Debug build run from Xcode shows a small, dismissible reminder that it updates by rebuild, not auto-update — so "why won't it update?" is answered up front.
