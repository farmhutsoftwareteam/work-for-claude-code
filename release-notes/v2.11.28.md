# Atelier 2.11.28 — Model picker shows what's actually latest, and a real performance pass

- **The model picker now groups by generation** — LATEST, PREVIOUS, LEGACY — derived from each model's own version number relative to what your installed CLI reports, not a hardcoded list. Opus staying on 4.8 while Sonnet and Fable moved to 5 is now visible instead of reading as one flat, undifferentiated list.
- **Fixed the worst freeze in the app.** Attaching a file in the Codex composer could block the whole app for several seconds — confirmed with real crash-trace evidence. Fixed at the source, with a safety net so it can't happen silently again.
- **Fixed a `~/.claude.json` bug that could freeze the app on "approve" or "add project"** — both used to rewrite your entire global config synchronously; now they're off the main thread and can't race each other and silently drop a write.
- **Fixed a bug where a finished agent's card could briefly show a different agent's data** in the live Agents panel.
- **A broad round of performance fixes** across skill management, the agents panel, file previews, and MCP panels — synchronous disk/subprocess work that could stall the UI is now backgrounded throughout.
